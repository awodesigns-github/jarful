# jar.riv (Jarful Phase 2)

`scene.rml` is generated by `../gen_rml.py` from `../jar-layers.svg`, which was exported from the Figma Jar component set. To change it, edit the generator and run `python3 gen_rml.py`.

## Build the .riv on your machine (needs `rive login`)

    cd rive
    rive .                  # live preview window; press d to edit data
    rive . --publish        # signed build/jarful-jar.riv for the app
    rive push               # optional: upload it as a file in your Rive account / editor

## Drive it from the app (view model JarVM)

| Property | Type | Use |
|---|---|---|
| fillLevel | number | 0 empty, 1 few, 2 half, 3 full (floats), 4 sealed |
| face | enum | waiting, happy, sleepy |
| noteColour | colour | colour of the slip dropping in / rising out |
| reducedMotion | boolean | every move becomes a short fade |
| glassColour, lineColour, labelColour | colour | theme: light FFFFFF/2E2A26/FBF6EC, dark 2D2621/F3EBDD/221C18 |
| dropNote, revealNote, tapJar, seal, celebrate | trigger | app → jar |
| noteLanded, noteRevealed | trigger | jar → app (haptic on these) |

The jar sets some values itself: dropNote sets face = happy when the slip lands, and seal sets fillLevel = 4 and face = sleepy. tapJar wiggles when fillLevel is 0 and ripples otherwise. Triggers fired mid-animation are ignored.

The `Intro` artboard (view model IntroVM, reducedMotion) plays its 3 s loop twice and then holds on the happy frame.
